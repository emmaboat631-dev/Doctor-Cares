Doctor Cares

Design System & Screen Gallery

Healthcare, anytime, anywhere. A mobile-first PWA + Android app that connects patients, doctors, and administrators — with real-time chat, appointment booking, drug information from OpenFDA, and secure medical records. Currency: Ghana Cedis (GH₵).

React · Vite · TypeScript Tailwind CSS Supabase (Auth · Postgres · Realtime · Storage) Capacitor Android Vercel
